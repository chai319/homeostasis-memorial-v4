# 恒常性メモリアル V4

高校生物の「体内環境の維持」を題材にした、観察と交流の学園ゲームです。
入学から学園祭まで、授業・放課後の活動・休日の外出を通じて人物を知り、結末を迎えます。

**[ブラウザーで遊ぶ](https://chai319.github.io/homeostasis-memorial-v4/)**

## 遊び方

- 主人公と攻略相手の性別を選び、「はじめから」で開始します。
- 台詞欄をタップして進め、選択肢で行動を決めます。
- 手帳で能力・人物・観察メモを確認できます。
- 手帳の「人とのつながり」から立ち絵図鑑を開けます。本編で見た差分を収集し、未収集はシルエットで表示します。収集は同じブラウザーで周回しても残ります。
- 保存は利用中のブラウザー内に残ります。同じブラウザーの「つづきから」で再開します。
- BGM・効果音・演出は設定から変更できます。

スマートフォン・タブレットでは横向き推奨です。プレイ時間は約30分を目安にしていますが、読む速さや遊び方によって変わります。

## 公開版

V4.5の全編、身体・表情の演出改善、および2026年10月20日追加のエンディングを収録しています。
最終後日談の後に、劇中の台詞と男女交互のキャスト紹介、スタッフのエンドロールを再生します（約3分・スキップ／再視聴可）。
[エンドロールを試写する](https://chai319.github.io/homeostasis-memorial-v4/credits-preview.html) ではゲームの保存を変更しません。
画像は元PNGと復号後の画素が一致する可逆圧縮WebP、音楽は元MP3を使用しています。
古いローカル版専用の継続リンクと制作記録は公開版に含めていません。

この作品は学習用の創作です。人物や物語上の比喩は、実際の生理機構を簡略化しています。

## ローカル起動

```sh
python3 -m http.server 8895 --bind 127.0.0.1
```

その後 `http://127.0.0.1:8895/` を開きます。ビルドやサーバー側の処理は不要です。
GitHub Pagesは `main` ブランチ直下から配信します。

ゲーム・画像・音楽の権利は各権利者に帰属します。
